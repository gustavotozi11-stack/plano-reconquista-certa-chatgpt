# Plano Reconquista Certa

Arquivos estáticos do site, enviados para este repositório a partir da versão atual do projeto Sites.

## Arquivos

- `index.html`: conversa principal.
- `oferta.html`: página da oferta secundária.
- `app.js`, `flow.js`, `branches.js`, `style.css`: comportamento e aparência.
- `assets/`: imagens, fontes e áudio.

Para visualizar localmente, abra `index.html` em um navegador. Para publicar com GitHub Pages, configure Pages para usar a branch `main` e a pasta raiz.
